# מערכת הגרפים — Novolog

מערכת שהופכת קבצי אקסל של דוחות תפעוליים למצגת גרפים אינטראקטיבית בסגנון PowerPoint, בעברית (RTL) ובצבעי המותג של Novolog.

## שימוש

1. פותחים את `login.html` בדפדפן ומתחברים.
2. גוררים קבצי אקסל למסך ההעלאה — המערכת מזהה את סוג הדוח אוטומטית.
3. לוחצים **צור מצגת** — כל נושא הופך לשקף מלא־מסך עם גרפים אינטראקטיביים, ניווט בחיצי המקלדת, תפריט נושאים ותצוגת טבלה לכל גרף.

## דוחות נתמכים

| דוח | זיהוי | שקפים |
|---|---|---|
| העברות למחסן פגומים | גיליונות `פגומים` / `SUM` / `השמדות` | שער, שווי לפי חודש, סיבות מובילות, פריטים מובילים, פגומים לפי סיבה, השמדות |
| ספירות מלאי | כותרת `מסמך ספירת מלאי` | שער, ספירות לפי חודש, הפרשים, דיוק ספירה, לפי סיבה, לפי אזור |
| קובץ אחר | — | גרף אוטומטי כללי + טבלה |

קבצים עם תוכן זהה מזוהים אוטומטית ומסומנים. אפשר להסיר קובץ מהרשימה עם אייקון הפח ולהעלות גרסה מעודכנת בלי לרענן.

## מבנה

- `login.html` — מסך התחברות (אימות צד־לקוח, סיסמאות כגיבוב SHA-256)
- `system.html` — המערכת: העלאת קבצים, פענוח, מנוע גרפי SVG ומצגת שקפים
- `lib/xlsx.full.min.js` — SheetJS לקריאת אקסל (מקומי, עובד ללא אינטרנט)
- `lib/fonts/` — גופן Assistant מקומי

> **הערה:** קבצי הנתונים (`*.xlsx`) אינם כלולים בריפו — הם נתוני לקוח.
